# M20 experimental native math

Optional Linux x86-64 spike. No historical Godot command needs a compiler or these
libraries. `.gdignore` prevents editor discovery; only explicit backend selection
loads the descriptor generated by the build. Do not commit generated binaries,
bindings, API dumps, verbose traces or toolchain downloads.

Prerequisites: Godot **4.6.3**, GCC **14.2.0** in this experiment, Rust **1.91.1**,
Python **3.12.14**, SCons **4.9.1**, official godot-cpp revision
**abb196939767b7bbee0b3a380faefdcbdb118a54**. Rust has no crate dependencies.
Acquire tools outside this repository; the build script performs no downloads.
The official SDK now versions independently; the obsolete `godot-4.6-stable` tag
is absent. Use the pinned revision and API explicitly:

```sh
mkdir -p work/native-deps
# Fetch this exact revision, not a floating branch/tag.
git -C work/native-deps init godot-cpp
git -C work/native-deps/godot-cpp remote add origin https://github.com/godotengine/godot-cpp.git
git -C work/native-deps/godot-cpp fetch --depth 1 origin abb196939767b7bbee0b3a380faefdcbdb118a54
git -C work/native-deps/godot-cpp checkout --detach FETCH_HEAD
# Writable XDG directories from the root README must be configured first.
(cd work/native-deps && godot --headless --no-header --dump-extension-api)
python3 scripts/tools/build_native_math.py --godot-cpp work/native-deps/godot-cpp --api work/native-deps/extension_api.json --sanitize
```

The shared official C++ bridge calls two separate libraries through the same C
ABI. The checked binary schema is in [SCHEMA.md](SCHEMA.md). Three batched native
calls per decision, not per loaf, forecast scalar, or future-day operation.
Borrowed inputs, fresh outputs, no authoritative state, no global model caches.
`-O3 -fno-fast-math -ffp-contract=off`; Rust release opt-level 3, one codegen unit,
no FMA feature or relaxed arithmetic. The Linux bridge has an `$ORIGIN` runpath.
No port/export support beyond this measured platform is claimed. Rust aborts on
panic/OOM; the bounded parser/math must reject ordinary bad inputs without panic.

```sh
godot --headless --path . --script res://scripts/tools/run_simulation.gd -- --scenario settlement_spatial_learning --stage D --backend rust 30 42 --report-json
# Or --backend cpp; omission/--backend gdscript uses the original policy path.
godot --headless --path . --script res://tests/run_native_math_tests.gd
python3 -B -m unittest discover -s tests -p test_native_math.py
```

See [M20 results](../../docs/M20_RESULTS.md) for corpus extraction, independent
verification, benchmarking commands, measured limitations and retained defaults.
This tests arithmetic portability; it is not a new simulation authority or a
commitment to either language.
